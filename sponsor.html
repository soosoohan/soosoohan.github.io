후원 방법 (How to Sponsor)

후원은 GitHub Sponsors 를 통해 이루어집니다.
You can sponsor Soosooland through GitHub Sponsors.
🔒 GitHub는 여러분의 결제 정보를 최고 수준의 보안 기술로 보호하며,
전 세계 1억 명 이상이 신뢰하는 안전한 플랫폼입니다.

후원 절차 (Steps)

1. 후원 페이지 접속
• https://github.com/sponsors/soosoohan 접속하세요
• 원하는 금액 선택 ($1, $3, $5)
• "Select" 버튼 클릭

2. GitHub 계정 만들기
• 로그인 정보 입력하세요
(깃허브 계정이 없으면 구글이나 애플 아이디로 로그인하세요)
• 영어 이름과 주소(한글 가능)를 입력하세요
• 국가(Korea)를 선택하세요.
• Postal/Zip code (우편번호)를 입력하세요
• VAT(부가가치세)/GST(상품 서비스세) ID는 사업자만 입력하는 항목이에요
• 한국에서는 사업자 등록번호를 적거나 개인 후원이면 비워 두세요.

3. 결제 정보 입력
• Card number (카드번호) 입력
• Expiration date (유효기간) 입력
• CVC (뒷면 3자리 숫자) 입력
• Billing address (청구지 주소) 입력
• 해외결제 가능한 카드가 필요합니다

4. 후원내용을 공개할 지 비공개할 지 선택합니다.
